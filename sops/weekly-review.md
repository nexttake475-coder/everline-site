# Weekly Review SOP

Standard Operating Procedure for weekly review meetings and assessments.

## Pre-Review (Monday Morning)

- Compile weekly metrics
- Gather logs and reports
- Document issues

## Review Meeting

1. Performance review
2. Pipeline analysis
3. Issue resolution
4. Planning for next week

## Post-Review (Friday)

- Archive reports
- Update documentation
- Schedule follow-ups
- Send summary
